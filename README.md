# Microsoft Endpoint Management Projects

Hands-on IT administration projects demonstrating Microsoft Intune, Microsoft Entra ID, Windows 11 endpoint management, device compliance, application deployment, and IT troubleshooting.

## About This Portfolio

This portfolio showcases practical endpoint management and IT administration skills developed through hands-on implementation, configuration, troubleshooting, and testing in a Microsoft 365 lab environment.

The focus is on solving realistic IT problems, managing Windows devices, applying security settings, investigating technical issues, and documenting verified outcomes.

## Featured Projects

### Project 1: Enterprise Windows Endpoint Management

**Objective:** Configure and manage a Windows 11 endpoint using Microsoft Intune and Microsoft Entra ID.

**Technologies:** Microsoft Intune, Microsoft Entra ID, Windows 11 Enterprise, Microsoft 365.

**Areas covered:**

- Microsoft Entra ID device join and Intune enrollment
- Device configuration and compliance policies
- Windows application deployment
- Endpoint security and Windows Firewall configuration
- Windows Local Administrator Password Solution (Windows LAPS) policy configuration
- Device management validation and troubleshooting

**Outcome:** Configured and validated a centrally managed Windows endpoint, with supporting screenshots and implementation documentation.

### Project 2: Endpoint Compliance and Access Troubleshooting

**Objective:** Investigate a browser security warning encountered while accessing SharePoint from a Windows 11 test device and document the troubleshooting process.

**Technologies:** Microsoft Entra ID, Microsoft Intune, Windows 11, Microsoft 365, Entra sign-in logs.

**Areas covered:**

- Investigating a browser certificate-date warning
- Reviewing Microsoft Entra sign-in results
- Checking the Windows Time service
- Correcting the service startup configuration
- Verifying SharePoint access after troubleshooting
- Documenting findings and distinguishing confirmed results from suspected causes

**Outcome:** Restored access during the troubleshooting session and documented the investigation. The precise root cause was not conclusively established.

[View Project 2](Project-02-Compliance-Access-Troubleshooting/README.md)
