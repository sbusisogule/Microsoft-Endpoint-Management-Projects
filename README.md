# Microsoft Endpoint Management Projects

Hands-on IT administration projects demonstrating Microsoft Intune, Microsoft Entra ID, Windows 11 endpoint security, device compliance, and PowerShell automation.

## About This Portfolio

This portfolio showcases practical endpoint management and IT administration skills developed through hands-on implementation, configuration, troubleshooting, and testing in a Microsoft 365 lab environment.

## Featured Projects

**Objective:** Configure and manage a Windows 11 endpoint using Microsoft Intune and Microsoft Entra ID.

**Technologies:** Microsoft Intune, Microsoft Entra ID, Windows 11 Enterprise, Microsoft 365.

**Areas covered:**
- Entra ID device join and Intune enrollment
- Device configuration and compliance policies
- Windows application deployment
- Endpoint security and firewall configuration
- Windows Local Administrator Password Solution (Windows LAPS)
- Device management validation and troubleshooting

**Outcome:** Demonstrate the configuration and management of a centrally managed Windows endpoint.

*Project status: Implementation and validation documentation in progress.*
