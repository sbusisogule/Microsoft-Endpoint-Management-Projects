# Microsoft Endpoint Management Projects

Hands-on projects demonstrating practical experience with Microsoft Intune, Microsoft Entra ID, Windows 11 endpoint management, compliance verification, application deployment, and troubleshooting.

These projects were completed in a personal Microsoft 365 lab environment to practise common endpoint administration and support tasks.

## Projects

### Project 1: Endpoint Management

Configure and validate a Windows 11 endpoint using Microsoft Entra ID and Microsoft Intune.

**Key areas:**
- Entra ID device join and Intune enrollment
- Device compliance and security settings
- Application deployment and verification
- Windows security controls and LAPS policy configuration

[View Project 1](Project-01-Endpoint-Management/README.md)

### Project 2: Compliance and Access Troubleshooting

Investigate an access issue affecting a lab user and document the troubleshooting process and findings.

**Key areas:**
- SharePoint access investigation
- Entra ID sign-in log review
- Windows Time service checks
- Evidence-based troubleshooting and documentation

[View Project 2](Project-02-Compliance-Access-Troubleshooting/README.md)

### Project 3: Windows 11 Endpoint Troubleshooting and Incident Resolution

Investigate common Windows endpoint concerns, validate system health, and verify Intune management status.

**Key areas:**
- Windows Update and Event Viewer investigation
- Application installation verification
- Windows Time service and synchronisation checks
- System file, disk, and Microsoft Defender health checks
- Intune compliance and device-record verification

[View Project 3](Project-03-Windows-Endpoint-Troubleshooting/README.md)

## About This Portfolio

This portfolio records practical lab work and the findings from each investigation. It distinguishes between configurations that were applied, checks that were completed successfully, and issues whose root causes were not conclusively established.
