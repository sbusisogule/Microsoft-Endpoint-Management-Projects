# Project 1 — Enterprise Windows Endpoint Management

This project demonstrates the deployment, management, security, and validation of a Windows 11 corporate endpoint using Microsoft Intune and Microsoft Entra ID.


## Technologies

- Microsoft Intune
- Microsoft Entra ID
- Windows 11 Enterprise
- PowerShell
- Windows LAPS
- Windows Defender Firewall
- Win32 application deployment
